# 第四章　海上貨物運輸保險

## 一、貨物運輸流程

出口商（賣方）倉庫 → 貨櫃場、海關倉庫、航空貨運站、保稅倉庫 → 運輸 → 進口地貨櫃場、海關倉庫等 → 進口商（買方）倉庫。

## 二、貿易條件（Incoterms®）

::: tip
**口訣**：貿易條件裡有 **I**（Insurance），由**賣方**買保險；沒有 I，由**買方**買保險。
:::

現行版本為 **Incoterms® 2020**。FOB、CIF 的風險，在貨物於裝運港**裝上船（on board）**時移轉給買方。

| 條件 | 意義 | 運費 | 保險 | 風險移轉 |
|---|---|---|---|---|
| **EXW**（Ex Works）工廠交貨 | 賣方在自己的工廠備妥貨物，由買方提取 | 買方 | 買方 | 在賣方處所交貨時 |
| **FOB**（Free On Board）船上交貨＋指定**裝運港** | 賣方負責把貨物裝上買方指定的船 | 買方 | **買方** | 貨物裝上船時 |
| **CIF**（Cost, Insurance and Freight）＋指定**目的港** | 賣方負擔到目的港的運費並投保 | 賣方 | **賣方** | 貨物在裝運港裝上船時（賣方雖投保，風險仍在裝船時移轉給買方，保險利益由買方承受） |

- **CIF 的保險要求（Incoterms 2020）**：賣方至少投保 **ICC(C)** 或同等條款，保險金額至少為契約價金的 **110%**。另一條件 **CIP** 則提高為 **ICC(A)**。
- **FOB 下的賣方**：貨物裝上船後，賣方的保險利益消滅；之後的海運及內陸運輸保險由買方安排。

**買賣雙方如何選擇（以賣方立場）**

| 宜選 FOB（買方買保險） | 宜選 CIF（賣方買保險） |
|---|---|
| 運價有上漲趨勢（本國幣升值） | 運價有下跌趨勢（本國幣貶值） |
| 進口港壅塞 | 進口港不壅塞 |
| | 貨物為活鮮或易腐品 |
| | 以郵包、快遞寄送 |

買方（進口商）立場則相反。

## 三、運輸保險的損失型態

| 型態 | 說明 | 舉例 |
|---|---|---|
| **實際全損**（Actual Total Loss） | 標的物因承保事故毀損滅失，已失去原有用途 | 水泥遇水結塊 |
| **推定全損**（Constructive Total Loss） | 實際全損已無法避免，或救助、修復費用將超過標的價值 | |
| **協議全損** | 雙方協議以全損處理 | |
| **共同海損**（General Average） | 航程中為求共同危險中全體財產的安全，所作**故意及合理**的處分，直接造成的犧牲與費用（海商法 §110） | 拋棄部分貨物以保全船貨 |
| **單獨海損**（Particular Average） | 非共同海損的部分損失，由受損方自行負擔 | 甲板貨物被大浪捲落海 |
| **損害防止費用**（Sue & Labour Charges） | 被保險人在貨物到達前，為防止或減輕損失所支出的合理費用 | |
| **施救費用**（Salvage Charges） | 船貨遇難時，給付第三人救助的報酬 | |
| **單獨費用**（Particular Charges） | 被保險人為保全標的物所支出，非屬共同海損或施救費用的費用 | 目的地的整理費用 |
| **額外費用**（Extra Charges） | 證明損失的費用，例如查勘、公證、理算費用（公證費由被保險人先支付） | |

**共同海損的成立要件**

1. 船貨共同遭遇真實而立即的危險。
2. 船長的處分出於自願且合理。
3. 造成非常的犧牲或費用。
4. 處分的目的是保全共同航海中的船貨。
5. 處分產生效果，船貨獲得保全。

## 四、運輸保險保單的性質

1. **航程保單**：效力只及於特定航程，例如進出口貨物運輸保單。
2. **時間保單**：以特定期間為效期，例如**協會船舶時間保險條款（I.T.C.）**。船體、航空機體保單多為時間保單。
3. 海上貨物運輸保險屬**定值保單**。
4. **投保時機**：應在危險開始前，也就是開始運送貨物之前。
5. **效力開始**：貨物離開保單所載起運地的倉庫或儲存處所時。
6. **T.B.D. 保單**（To Be Declared）：資料尚未齊全，待通知的保單。
7. **不足額保險**（保額小於發票金額）：發生全損時以保險金額為限；部分損失依比例分攤。
8. 承保時對船舶的考量：是否為老船、小船、貨櫃船。
9. 市場上所稱「水險」，通常特指**海上貨物運輸保險**。
10. 貨物內陸運輸中文保單，被保險人的求償時效為 **2 年**。

## 五、協會貨物保險條款（ICC）

英國倫敦保險人協會訂定的 Institute Cargo Clauses，分為 ICC(A)、ICC(B)、ICC(C) 三種。

| 承保範圍 | 新式條款（1982 年版；2009 年修訂版沿用 A/B/C） | 舊式條款（1963 年版） |
|---|---|---|
| 全險 | ICC (A) | ICC (All Risks) |
| 水漬險 | ICC (B) | ICC (W.A.／With Particular Average) |
| 平安險 | ICC (C) | ICC (F.P.A.／Free from Particular Average) |
| 空運全險 | ICC (Air) | Institute Air Cargo Clauses (All Risks) |
| 兵險 | Institute War Clauses (Cargo) | 同左 |
| 罷工險 | Institute Strikes Clauses (Cargo)／(Air Cargo) | S.R.C.C.（罷工、暴動及民眾騷擾） |

::: tip
**補充**：倫敦市場於 2009 年 1 月 1 日發布 **ICC 2009** 修訂版，承保架構仍為 A、B、C 三種。我國實務上新、舊條款**併用**，考題多沿用 1982 年版用語。
:::

- **概括式**：除了列明的除外事項外，都承保。**A 條款**屬之，範圍最大。
- **列舉式**：只承保列明的事故。**B、C 條款**屬之，B 條款範圍大於 C 條款。
- 新式協會貨物條款（含罷工險）下，貨物在目的港卸船後，最長效期以 **60 天**為限。
- 貨物運輸保險所稱「小船」，指 **1,000 噸以下**的商船。

**A、B、C 條款承保範圍比較**

| 項目 | A | B | C |
|---|:-:|:-:|:-:|
| 意外短少 | ○ | × | × |
| 水濕（海水、湖水、河水進入） | ○ | ○ | × |
| 貨櫃落海、海浪捲落 | ○ | ○ | × |
| 海盜、偷竊 | ○ | × | × |
| 內陸運送因綑綁不牢掉落 | ○ | × | × |
| 雙方過失碰撞 | ○ | ○ | ○ |
| 共同海損及施救費用 | ○ | ○ | ○ |
| 罷工損失 | × | × | × |
| 被保險人故意（惡意）行為 | × | × | × |
| 標的物固有瑕疵、品質不良、包裝不當 | × | × | × |
| 自燃焦損（如魚粉） | × | × | × |
| 營業中斷、遲延造成的市場跌價 | × | × | × |
| 船東財務糾紛（破產、債務不履行）造成的損失 | × | × | × |
| 原子、核子武器 | × | × | × |
| 出口商疏漏少裝（如電腦少 10 台） | × | × | × |

### 兵險與罷工險

- **兵險**：自貨物**裝載上海輪時**開始生效。承保戰爭、內戰、革命、叛亂、交戰行為，以及由此引起的捕獲、拘留、扣押；也承保遺棄的水雷、魚雷、炸彈等戰爭武器造成的損失。
- **罷工險**：承保罷工、停工、工潮、暴動、民眾騷擾人員所致的損失，以及**恐怖主義**或政治動機所致的損失（例：美國 911 事件），並承保為避免上述損失而生的共同海損與施救費用。

### 主要除外條款

1. **不適航、不適運**：載運船舶或駁船不適航，或運輸工具、貨櫃不適合安全運送，所引起的損失。但必須是**被保險人或其受僱人在裝載時已知情**才除外；不知情者仍承保。
2. **兵險除外**：戰爭、捕獲扣押（**海盜除外**）、遺棄的戰爭武器。可另加保**協會貨物兵險條款**。
3. **罷工除外**：罷工、暴動、民眾騷擾人員所致；恐怖分子或政治動機所致。可另加保**協會罷工險條款**。

## 六、常見名詞

- **流動保單**（Floating Policy）：事先約定總保險金額，承保多次運送，保額依每次申報遞減，直到用完為止。
- **免責責任比率**（Franchise，起賠式）：損失未達約定比率時不賠；超過時**全部**賠付。

> **練習**　保額 US$10,000，損失 US$1,000，Franchise 3%。
> **答**　門檻 US$300，損失已超過，賠付 **US$1,000**。

- **超過自負額比率**（Excess，扣減式）：只賠超過約定比率的部分。

> **練習**　保額 US$10,000，損失 US$1,000，Excess 3%。
> **答**　US$1,000 － US$300 ＝ **US$700**。

- **J.W.O.B.**：Jettison and/or Washing Overboard，投棄及海浪捲落。
- **海盜**：以強暴脅迫取得他人財物。**不包括**秘密偷竊，或船員、旅客的偷竊。ICC(A) 承保；ICC(B)、(C) 不承保。
- **FCL**（整櫃）／**LCL**（併櫃）。整裝分拆的運輸方式，在提單上以 **FCL/LCL** 表示。
- **異常（破損）證明**：提貨時發現包裝破損，應要求運送人或海關出具。
- **R.O.D.**：Rust, Oxidation and Discoloration，生鏽、氧化及變色。

## 七、費率釐訂考量

| 會影響費率 | 較不影響 |
|---|---|
| 中途轉船（風險增加） | 氣溫 |
| 航程遠近（越遠越高） | 是否開立信用狀 |
| 季節（颱風季節較高） | 貨物本身品質 |
| 包裝（越牢固越低） | |
| 船齡（散裝混合貨輪船齡 10 年以上須加費） | |
| 客戶損失紀錄 | |
| 貨物性質（高價易碎品費率較高） | |

## 八、理賠注意事項

1. **全損索賠**：須提出**全套保單正本**與**全套提單（B/L）正本**，證明有權索賠。
2. 提貨時發現包裝破損，應取得異常（破損）證明。

## 九、漁船船體保險（採英國協會條款）

1. **保險標的**：船體及設備機件。
2. **保險價額**：以保險人責任開始時的船價為準。
3. **航行區域**：受一定地區限制。
4. **建造期間**：可投保漁船建造保險。
5. **P&I 保險**：船東防護及補償保險。
6. **承保條件限制**：全損險附加施救費用。
7. **國內投保方式**：自行向保險公司投保、船東以合作社方式共同承保、透過經紀人投保。

## 十、其他重點

1. 貨物運輸保險的**保險價額**，以發票中的 **CIF 金額**為依據；保險金額依慣例為 CIF 金額**加 1 成**（110%）。
2. **關稅利益**可以附加投保。

> **練習**　進口汽車投保貨物運輸保險 US$15,000，另附加進口關稅保險 US$6,000。已繳關稅後於內陸運輸中被火燒毀全損，應賠多少？
> **答**　US$15,000 ＋ US$6,000 ＝ **US$21,000**。

3. 高價花瓶與廉價花瓶同樣投保 A 條款，**廉價花瓶的費率較低**。
