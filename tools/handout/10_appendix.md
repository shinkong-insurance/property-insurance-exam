# 附錄　常考數字速記

## 期間類

| 數字 | 內容 |
|---|---|
| 24 小時 | 竊盜險知悉後通知保險公司；車體險通知後保險公司未處理即可修理 |
| 72 小時 | 颱風洪水險、營造綜合保險（地震）視為一次事故 |
| 168 小時 | 住宅地震基本保險視為一次事故 |
| 3 日 | 強制險契約終止後通知監理機關 |
| 5 日 | 危險發生通知；業務員異動申報；車險出險通知書；責任險收到起訴書後送交 |
| 7 日 | 竊盜險提出申請書及損失清單；失竊車尋回後領回期限 |
| 10 日 | 危險增加（非因己）通知；車險過戶後申請權益移轉；強制險給付期限為 10 個**工作日** |
| 14 日 | 出院後同一原因再住院，視為同一次住院 |
| 15 日 | 保險金給付（保險法、任意車險）；保險公司因詐欺終止前須預先通知 |
| 30 日 | 營造險連續停工除外；試車期間上限；竊盜險尋車期；強制險續保通知；商業火險提出理賠文件；強制險看護最多天數；醫療險等待期 |
| 45 日 | 健保代位，強制險保險人確定給付期限 |
| 60 日 | 建築物無人看管視為空屋；玻璃險無人居住；ICC 卸貨後最長效期 |
| 90 日 | 癌症險、重大疾病險等待期；日額型醫療每次給付上限；資本嚴重不足逾期未改善，主管機關接管等處分期限 |
| 180 日 | 傷害險死亡、失能、醫療給付期限 |
| 1 個月 | 解除權除斥期間（知悉）；暫保單效期；罰鍰延期繳納上限 |
| 3 個月 | 被保險人破產、死亡後的契約終止或權益移轉期間；住宅火險讓渡後仍有效期間 |
| 6 個月 | 機能永久喪失判定；強制險通知存根保存；行車事故鑑定申請期限；微電車逾期未保可註銷牌照 |
| 2 年 | 解除權（訂約後）；保險法請求權時效；強制險時效（知悉）；任意車險時效 |
| 5 年 | 業務員登錄證效期；業務員停止招攬累計的計算期間；個資法損害賠償（發生後） |
| 10 年 | 強制險請求權（事故發生後） |
| 15 個工作日 | 備查制商品開始銷售後送主管機關備查 |
| 40／75 個工作日 | 核准制商品：主管機關核復／准駁決定 |
| 25／45 個工作日 | 核准制商品駁回後再送審：核復／准駁決定 |
