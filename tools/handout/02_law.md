# 第二章　財產保險法規

## 一、保險契約的定義與分類

- **保險契約**：依保險法第 1 條約定的契約。要保人交付保費，保險人對不可預料或不可抗力的事故所致損害負賠償責任。
- **保險的分類（保險法第 13 條）**：分為**財產保險**與**人身保險**。
  - **財產保險**：火災保險、海上保險、陸空保險、責任保險、保證保險，以及經主管機關核准的其他財產保險。
  - **人身保險**：人壽保險、健康保險、傷害保險、年金保險。
- 航行內河船舶的運費及裝載貨物保險，除陸空保險另有規定外，**準用海上保險**的規定。

> **練習**　下列何者**不屬**保險法所定的財產保險？①火災保險 ②陸空保險 ③保證保險 ④年金保險
> **答**　④。年金保險屬人身保險。

## 二、保險契約的當事人、關係人、輔助人與業務員

### （一）當事人

| 角色 | 定義 |
|---|---|
| **要保人**（§3） | 對保險標的具有保險利益，向保險人申請訂約，並負有交付保費義務的人 |
| **保險人**（§2） | 經營保險事業的組織。契約成立時有保費請求權，事故發生時依約負賠償義務 |

- 保險業的組織，以**股份有限公司**或**合作社**為限（§136）。
- 保險業負責人，指依公司法或合作社法應負責的人（§7）。

### （二）關係人

| 角色 | 定義 |
|---|---|
| **被保險人**（§4） | 事故發生時遭受損害、享有賠償請求權的人。要保人也可以是被保險人；產險實務上兩者多為同一人 |
| **受益人**（§5） | 由被保險人或要保人約定享有賠償請求權的人。要保人、被保險人都可以是受益人 |

### （三）輔助人

| | 保險代理人（§8） | 保險經紀人（§9） | 保險公證人（§10） |
|---|---|---|---|
| 立場 | 代表**保險人** | 基於**被保險人**利益 | 中立，向保險人或被保險人收費 |
| 依據 | 代理契約或授權書 | — | — |
| 主要工作 | 招攬、收費、核保出單、理賠等（依授權範圍） | 洽定保險契約、建議適當保險人與保障、風險管理建議、理賠協助 | 保險標的的**查勘、鑑定、估價、賠款理算、洽商**並予證明 |
| 法律效果 | 授權範圍內的行為，直接對保險人發生效力 | 財產保險經紀人應在**要保書、批改申請書、代繳保費收據**上簽署並負責 | — |

- 經紀人公司最低實收資本額為新臺幣 **500 萬元**；兼營再保險經紀業務者為 **1,000 萬元**。
- 經紀人應自許可登記之日起 **6 個月**內，申領執業證書並開始營業。
- 經紀人兼營再保險經紀業務時，專業責任保險的保險金額應為只經營經紀業務者的 **2 倍**。

**繳存保證金及投保責任保險（輔助人）**

| 項目 | 規定 |
|---|---|
| 保證金 | 個人執業：新臺幣 **10 萬元**<br>公司型態：前一年度營業收入未達 1,000 萬元者，**20 萬元** |
| 專業責任保險（每一事故） | 個人執業不低於 **100 萬元**；公司型態不低於 **200 萬元**；自負額不得超過保險金額 **10%** |
| 保證保險（僅經紀人） | 個人不低於 **100 萬元**；公司不低於 **200 萬元**；自負額不得超過 **10%** |

> **練習**　辦理保險標的查勘、鑑定、估價與賠款理算、洽商並予證明的是？
> **答**　保險公證人。

### （四）保險業務員

**定義（§8-1）**：為保險業、保險經紀人公司或保險代理人公司從事保險招攬的人。

**業務員的招攬行為（保險業務員管理規則）**：

1. 解釋保險商品內容及保單條款
2. 說明填寫要保書注意事項
3. 轉送要保書文件及保險單

**登錄資格**

- 業務員應**成年**（依民法，年滿 **18 歲**為成年），並須具**高中（職）以上**學校畢業或同等學歷。

- 業務員須**登錄**並領得登錄證，才能為所屬公司招攬。可招攬的保險種類，由所屬公司決定。
- 登錄後只能為**所屬公司**招攬；轉任其他公司時，須**重新登錄**。
- 登錄證有效期間為 **5 年**。
- 業務員資料異動時，所屬公司應於異動後 **5 日**內向公會申報。
- 業務員招攬所生的損害，所屬公司依法負**連帶責任**。

**教育訓練**

- 業務員應**每年**參加所屬公司辦理的教育訓練。
- **不參加**訓練，或訓練不合格且 **1 年內補訓仍不合格**者，所屬公司應**撤銷**其登錄。

**停止招攬與撤銷登錄**

| 項目 | 規定 |
|---|---|
| 停止招攬期間 | 業務員有招攬違規情事時，所屬公司應予**停止招攬 1 年以下** |
| 撤銷登錄 | **最近 5 年內**受停止招攬處分期間**累計達 2 年**者，應撤銷其登錄 |
| 撤銷後再登錄 | 受撤銷登錄處分者，應**重新參加資格測驗合格**，始得再辦理登錄 |
| 停招期間的登錄限制 | 停止招攬期間內，不得登錄**同類**保險。例如壽險停招期間，仍可登錄產險 |
| 公司處分的範圍 | 業務員招攬違規，所屬公司依規定處以停止招攬，不得逕予撤銷登錄 |
| 救濟管道 | 業務員可向原公司**申復**一次，不服再向公會**申訴委員會**請求覆核一次（委員會應有業務員代表） |

::: tip
**考試注意**：題庫第 68 題仍依舊規定，答「撤銷登錄之日起**三年**內不受理登錄」。
:::

**保險業辦理電話行銷**

- 電話行銷人員應具備業務員資格。
- 電話行銷傷害保險的保險金額，不得超過新臺幣 **600 萬元**。
- 行銷過程與成交紀錄應錄音存檔，保存期限不得少於契約**期滿後 5 年**。

## 三、保險契約的成立與效力

### （一）契約成立

- 要保人對單純的期待利益**沒有**保險利益。
- 運送人可以為自己承運的貨物投保**貨物運送人責任保險**。

### （二）契約效力的各種型態

| 型態 | 效力 | 舉例 |
|---|---|---|
| 無效 | 自始無效 | 惡意複保險；訂約時危險已發生 |
| 解除 | **溯及**既往失效 | 違反告知義務、違反特約條款 |
| 撤銷 | **溯及**既往失效 | 意思表示有瑕疵 |
| 終止 | 自終止時起失效，**不溯及** | 危險增加，保險人要求加費但要保人不同意 |
| 失效 | 自失效時起失效 | 喪失保險利益 |
| 停止 | 停止原因消滅後恢復效力 | 停效後復效 |

- 被保險人死亡或保險標的所有權移轉時，契約除另有約定外，仍為**繼承人或受讓人**的利益存在（§18）。

### （三）契約內容

- **戰爭**所致損害，除契約有相反約定外，保險人應負賠償責任（§32）。
- 保險契約應以**保險單**或**暫保單**為之。暫保單用於正式保單簽發前，證明保險人的責任，實務上效期通常為 **30 日**。
- **批單**的效力優先於原契約條款。
- 契約解釋應探求當事人真意；有疑義時，以作**有利於被保險人**的解釋為原則。
- 保險單應記載保險標的、保險事故種類、保險費等事項。

**特約條款（§66–§69）**

- 指當事人在基本條款外，承認履行特種義務的條款。
- 一方違背特約時，他方可以**解除契約**；危險發生後也一樣。
- 解除權準用第 64 條第 3 項：知悉後 **1 個月**內不行使而消滅；契約訂立後超過 **2 年**者，不得再解除（§68）。

**一方無須通知的情形**：為他方所知者；依通常注意為他方所應知或無法推諉為不知者；他方已聲明不必通知者。

### （四）保險金額相關規定

- **定值保險**：訂約時約定標的價值。
- **不定值保險**：標的價值於危險發生後估定。賠償以事故發生時的實際價值為準，最高以保險金額為限。
- **善意超額保險**：契約只在標的價值限度內有效。經當事人通知後，保險金額與保費均按標的價值比例減少。

> **練習**　契約上載明保險標的之價值須至危險發生後估計而定，是哪一種保險？
> **答**　不定值保險。

### （五）保費與準備金

- 產險責任準備金包括：未滿期保費準備金、特別準備金、賠款準備金。
- 保費可一次交付或分期交付。

### （六）契約終止

- 保險標的**非因承保事故**而全部滅失時，契約即終止；終止後已交付的保費應返還。
- 要保人破產時，契約仍為破產債權人的利益存在；但破產管理人或保險人可於破產宣告後 **3 個月**內終止契約。

## 四、理賠與通知義務

1. 未在法定期限內通知危險發生或危險增加時，對保險人因此所受的損失，應負賠償責任。
2. 為**救護保險標的**而造成的損失，視同承保危險所生的損失。
3. 火災保險人應賠償：標的物的毀損滅失、因救護標的所致的損失，以及避免或減輕損失的必要費用。
4. **不定值的不足額保險**：保險人對證明及估計損失所支出費用的負擔，依保險金額對標的價值的比例計算。
5. 要保人或被保險人未盡合理方法保護標的物，因而增加的損失，保險人不負賠償責任。

## 五、複保險、共同保險與再保險

| | 複保險 | 共同保險 | 再保險 |
|---|---|---|---|
| 定義 | 要保人對**同一保險利益、同一事故**，與**數保險人分別**訂立**數個**契約 | 要保人對同一保險利益、同一事故，與數保險人訂立**一個**契約 | 保險人將承保的危險，轉向其他保險人投保 |
| 理賠 | **善意**：在保險價額內，依各契約保險金額比例分擔<br>**惡意**：契約無效 | 依承保比例分擔 | 與原保險契約**各自獨立**。原被保險人對再保險人**沒有**賠償請求權 |

## 六、補充法規：洗錢防制法、個人資料保護法與金融消費者保護法

### （一）洗錢防制法


| 項目 | 現行規定 |
|---|---|
| 洗錢定義（§2） | ①**隱匿**特定犯罪所得或**掩飾**其來源；②**妨礙或危害**國家對特定犯罪所得的調查、發現、保全、沒收或追徵；③**收受、持有或使用**他人的特定犯罪所得；④使用自己的特定犯罪所得，與他人進行交易 |
| 特定犯罪（§3） | **最輕本刑 6 個月以上**有期徒刑之罪，以及法律列舉的罪名 |
| 金融機構（§5） | 包括銀行、**保險公司**、證券商、信託業等，以及其他經目的事業主管機關指定者 |
| 大額通貨交易申報 | 金融機構對達一定金額以上的通貨交易應申報。現行門檻為新臺幣 **50 萬元**（含等值外幣） |
| 國際合作 | 政府得依互惠原則，與外國政府、機構或國際組織簽訂防制洗錢合作條約或協定 |

### （二）個人資料保護法

| 項目 | 規定 |
|---|---|
| 立法目的（§1） | 規範個資的蒐集、處理及利用，避免人格權受侵害，並促進個資合理利用 |
| 蒐集（§2） | 以**任何方式**取得個人資料 |
| 利用（§2） | 將蒐集的個資作**處理以外**的使用 |
| 比例原則（§5） | 蒐集、處理或利用不得逾越**特定目的**的必要範圍 |
| 當事人權利（§3） | 查詢或請求閱覽、請求製給複製本、請求補充或更正、請求停止蒐集處理利用、請求刪除。這些權利**不得預先拋棄或以特約限制** |
| 損害賠償時效（§30） | 自請求權人**知有損害及賠償義務人時起 2 年**；自損害發生時起**逾 5 年**亦同 |

- 非公務機關違反**安全維護義務**者，處新臺幣 2 萬–200 萬元罰鍰；情節重大者處 15 萬–1,500 萬元。
- 獨立監督機關：**個人資料保護委員會**。

> **練習**　依個資法，損害賠償請求權自損害發生時起，逾幾年不行使而消滅？
> **答**　5 年。

### （三）金融消費者保護法（爭議處理）

| 步驟 | 規定 |
|---|---|
| 先申訴 | 金融消費者應先向金融服務業（如保險公司）提出**申訴** |
| 處理期限 | 金融服務業應於收受申訴之日起 **30 日**內為適當處理，並將結果回覆消費者 |
| 再評議 | 消費者不接受處理結果，或業者逾 30 日未處理，可在收受結果或期限屆滿之日起 **60 日**內，向**金融消費評議中心**申請評議 |

> **練習**　保險公司收到保戶申訴後，應於幾日內處理並回覆？
> **答**　30 日。
