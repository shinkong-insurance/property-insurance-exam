# 第一章　財產保險理論

## 一、危險與損失

### （一）危險的意義

危險是指**損失發生與否的不確定性**。如果損失一定不會發生，或者一定會發生，就不算危險。只要損失會不會發生、什麼時候發生、怎麼發生、損失多大其中任何一項不確定，就有危險存在。

### （二）危險的種類

| 類別 | 可能結果 | 舉例 | 可否保險 |
|---|---|---|---|
| **純損危險** | 只有「損失」或「無損失」，沒有獲利機會 | 火災、車禍、天災 | 可保 |
| **投機性危險** | 可能損失、無損失，也可能獲利 | 買股票、賭博、研發新產品 | 不可保 |

### （三）損失的種類

| 類型 | 內容 |
|---|---|
| 財產直接損失 | 財產本身毀損、滅失，價值減少。例：修理費、復原成本 |
| 財產從屬（間接）損失 | 因財產受損而衍生，例如營業中斷造成的固定成本與利潤損失、額外費用 |
| 法律賠償責任 | 因故意或過失不法侵害他人權利，依法應負的賠償，包括醫療費、喪葬費、財物修復、收入中斷、精神慰撫金等 |
| 體傷或死亡損失 | 因人身傷亡衍生的醫療、喪葬等額外費用與收入損失 |

### （四）危險因素

| 危險因素 | 說明 | 舉例 |
|---|---|---|
| **實質危險因素** | 有形財物本身影響損失發生的條件 | 建築結構、易燃物品 |
| **道德危險因素** | 被保險人不誠實、意圖不當得利，故意促成或擴大損失 | 惡意縱火、假車禍 |
| **怠忽（心理）危險因素** | 因為有保險，對損失漠不關心，該注意而不注意 | 廠房管理鬆散、貨物包裝不良、投保竊盜險後下車不鎖門 |

## 二、危險管理

### （一）目的與步驟

- **目的**：以最低管理成本，換取最大的保障效果。
- **步驟**：危險辨識 → 危險評估 → 選擇並執行危險管理措施 → 評估成效。
- **評估依據**：
  - **損失頻率**＝理賠次數 ÷ 保險單位數（發生次數多寡）
  - **損失幅度**＝損失總額 ÷ 理賠次數（每次損失大小）

### （二）危險管理措施

**1. 危險控制型**：從根本降低損失頻率或幅度。

| 措施 | 重點 | 舉例 |
|---|---|---|
| 避免危險 | 完全不從事可能產生損失的活動 | 怕出意外就不出門 |
| 損失預防 | 改善危險因素，**降低發生頻率** | 不酒駕、汽車保養、加裝防盜鎖、職安訓練 |
| 損失抑制 | 事故發生時防止擴大，**降低損失幅度** | 自動灑水設備、安全氣囊、船艙通風系統 |
| 非保險轉嫁 | **整體轉嫁**：把危險標的連同危險移轉給他人（如出售）<br>**損失轉嫁**：只移轉損失的財務負擔，標的仍在（如租約約定房客負火災賠償責任、零售商以買賣契約將瑕疵責任轉給製造商） | |

**2. 財務融通型**：損失難以完全避免，所以事先做財務安排。

- **損失自留**：自己有能力承擔；或損失率太高，無法用保險轉嫁。
- **保險轉嫁**：以繳保費的方式，把損失轉給保險人。

::: tip
**考點**：「保險轉嫁」與「損失自留」搭配運用，是危險管理措施的最佳組合；最典型的做法是在保險契約中訂**自負額**。
:::

**3. 危險管理矩陣**：依損失頻率與損失幅度選擇主要對策。

| 損失頻率 | 損失幅度 | 主要對策 |
|---|---|---|
| 低 | 小 | **損失自留**（此時買保險反而不經濟） |
| 低 | 大 | **保險**；問「組合」時答 **損失自留＋保險** |
| 高 | 小 | 損失預防＋損失自留 |
| 高 | 大 | **避免危險** |

- **避免危險**是唯一能讓損失頻率降為零的方法。
- **損失預防**是事前措施，降低頻率；**損失抑制**是事發時或事後措施，降低幅度（如救火、急救、出售殘餘物）。
- 損失自留的條件：幅度不大、自己財力吸收得了；預期損失可較準確估計；轉嫁或其他方法不可行或不經濟。

## 三、保險的功能

1. 損失補償（但不能讓被保險人因此額外獲利）
2. 減少憂慮
3. 促進損失預防（透過費率優惠及防災服務）
4. 提供信用基礎（貸款擔保品通常須投保）
5. 累積資金（責任準備金），支援企業及公共投資

::: tip
**陷阱**：「社會救濟」**不是**保險的功能。
:::

## 四、保險的定義與原理

- **定義（保險法第 1 條）**：當事人約定，一方（要保人）交付保險費給他方，他方（保險人）對於不可預料或不可抗力的事故所致損害，負擔賠償財物的責任。依此所訂的契約，稱為保險契約。
- **大數法則**：危險單位越多，實際損失越接近預期，保險經營才穩定、費率才合理。
- **損失分攤**：透過收取保費，把少數人的損失分攤給全體被保險人。

## 五、可保危險與不可保危險

**可保危險的要件**

1. 屬於純損危險
2. 危險單位數量多，而且性質相似
3. 損失可以用金錢衡量
4. 損失出於意外、偶然，不可預期
5. 損失大到個人難以自行負擔
6. 保費成本經濟合理
7. 損失機率可以估計
8. 一次事故不會同時波及大多數保險標的（無巨災集中）

**不可保危險**：被保險人的故意行為、股價漲跌等投機性危險、損失程度無法明確界定的危險、非出於偶然的損失。

## 六、保險基本原則

### （一）最大誠信原則

1. **告知義務（保險法第 64 條）**：訂立契約時，要保人對保險人的**書面詢問**應據實說明。如果故意隱匿、過失遺漏或說明不實，足以變更或減少保險人對危險的估計，保險人可以**解除契約**；危險發生後也一樣。但要保人能證明危險的發生與未說明的事實無關時，不在此限。
2. **解除權行使期限**：保險人**知道解除原因後 1 個月**內不行使，或**契約訂立後超過 2 年**，即使有解除原因，也不能再解除。
3. **契約訂立時危險已發生或已消滅**：契約無效；但雙方都不知情時，不在此限。訂約時只有要保人知道危險已發生，保險人不受契約拘束。


### （二）保險利益原則

保險利益是指要保人或被保險人對保險標的，因既存的利害關係而享有的經濟利益。財產保險要求**損失發生時**須具有保險利益；對保險標的無保險利益者，契約**失其效力**（保險法 §17，不是「無效」）。

- **存在目的**：避免賭博、防止道德危險、作為損失補償的衡量尺度。
- **要件**：合法利益、經濟利益、確定利益。
- **類型**：
  1. **現有利益**：如自有房屋。
  2. **責任利益**：如倉庫業者對寄存貨物、運送人對承運貨物的賠償責任。
  3. **期待利益**：如企業預期營業利益、運送人對貨物到達的運費利益。但「遺產繼承的期待」屬單純期待，**不具保險利益**。
  4. **代理而生的利益**：代理商對保管中的代理產品負有責任。

### （三）損害補償原則

保險的目的是讓被保險人恢復到損失發生前的狀態，不能因此獲利。

**1. 補償方式**

- **現金給付**：以重置成本（重新購置所需費用）或實際現金價值（＝重置成本－折舊）計算。
- **恢復原狀**：修復或置換。

**2. 保險金額與保險價額**

- **保險金額**：保險人在保險期間內負責的最高額度。
- **保險價額**：保險標的的實際價值。

| | 不足額保險 | 足額保險 | 超額保險 |
|---|---|---|---|
| 關係 | 保險金額 ＜ 保險價額 | 保險金額 ＝ 保險價額 | 保險金額 ＞ 保險價額 |
| 理賠 | **比例分攤**：賠款＝損失 ×（保險金額 ÷ 保險價額） | 依實際損失賠付 | **善意**：在保險價額限度內有效，依實際損失賠付<br>**惡意（詐欺）**：保險人可解除契約 |

**3. 定值保險與不定值保險**

| 比較 | 定值保險 | 不定值保險 |
|---|---|---|
| 價額決定時點 | 訂約時雙方約定 | 危險發生時估計 |
| 損失計算基礎 | 約定價值 | 實際現金價值（重置成本－折舊） |
| 損害補償原則 | 較不適用 | 較適用，**最符合補償精神** |
| 常見險種 | 海上貨物保險、藝術品保險 | 一般財產保險 |

採用定值保險的原因：標的市價難以確定、損失時不易估價、不易重置。

**4. 代位求償（保險法第 53 條）**

- 由損害補償原則衍生而來。
- 保險人**給付賠款後**，以**自己名義**行使，金額以賠償金額為限。
- 對被保險人的**家屬或受僱人**原則上不得代位；但損失是他們**故意**造成時，可以代位。

**5. 自負額**

| 類型 | 說明 | 水險用語 |
|---|---|---|
| **扣減式** | 每次損失都先扣自負額，只賠超過部分 | 超過自負額比率（Excess） |
| **起賠式** | 損失未達門檻全由被保險人負擔；超過門檻則**全額**賠付 | 免責責任比率（Franchise） |

> **練習**　自負額 30,000 元，損失 45,000 元。
> **答**　扣減式賠 15,000 元；起賠式賠 45,000 元。

**6. 損害補償原則的例外**：定值保險、重置成本保險。

### （四）主力近因原則

判斷損失是否由承保事故造成時，要找出導致損失最直接、最有效的原因。

## 七、保險契約的特性

| 特性 | 說明 |
|---|---|
| 射倖契約 | 訂約時無法確定事故是否發生。保險與賭博都有射倖性，但保險沒有獲利機會 |
| 附合契約 | 被保險人通常只能決定接受或不接受標準條款。特殊情況下，可在不違反強制規定時以批單修改 |
| 有償契約 | 要保人付保費，保險人負擔賠償責任 |
| 雙務契約 | 雙方互負對價義務 |
| 附條件契約 | 須檢具理賠文件等條件，才能請求給付 |
| 最大誠信契約 | 訂約時負有據實說明義務 |
| 對人契約 | 核保時除評估標的本身，也要了解要保人、被保險人的背景 |

- **依期間分**：時間保單（載明起訖日）、航程保單（以航程為準，不載明起訖日）。
- **依承保範圍分**：列舉式、概括式（全險）。
- **成立要件**：要約與承諾、當事人有行為能力、雙方的對價。要求行為能力，是因為無行為能力人的意思表示依法無效。
- **生效要件**：對價關係、目的合法、當事人有行為能力。

::: tip
**陷阱**：「被保險人遵守最大誠信原則」**不是**契約生效要件。
:::

## 八、相關數字彙整（保險法）

| 項目 | 規定 | 條文 |
|---|---|---|
| 危險發生通知 | 知悉後 **5 日**內（海上保險：立即通知） | 保險法 §58 |
| 危險增加通知 | 因要保人或被保險人行為所致：**事先**通知<br>非因其行為所致：知悉後 **10 日**內 | 保險法 §59 |
| 保險金給付期限 | 有約定從約定；未約定者，接到通知文件後 **15 日**內。可歸責於保險人而遲延時，加付**年利一分**利息 | 保險法 §34 |
| 解除權除斥期間 | 知悉後 **1 個月**；訂約後 **2 年** | 保險法 §64 |
| 請求權消滅時效 | 自得為請求之日起 **2 年**（有隱匿不實者自保險人知情日起算等例外） | 保險法 §65 |


## 九、保險契約文件、保單型式與除外不保

### （一）契約文件

| 文件 | 作用與考點 |
|---|---|
| **要保書** | 要保人的意思表示、重要事項的告知，也是保險人**核保的依據** |
| **基本條款** | 規範雙方權利義務、**普遍適用**的條款 |
| **特約條款** | 在基本條款之外，當事人承認履行特種義務的條款（個別約定） |
| **明細表** | 記載被保險人名稱、保險金額、保險費等；**不列**除外不保事項 |
| **暫保單** | **正式保單簽發前**，證明保險人已負責任；**正式保單簽發時失效** |
| **批單** | 訂約時或訂約後經雙方同意，**補充或變更**原契約內容 |

**暫保單的出具時機**：契約部分條件尚未確定；續保時條件還沒談妥；正式保單仍在繕製、被保險人急需保險證明。

**批單重點**

- 效力**優於**原契約條款；有多張批單時，**簽發日期愈晚，效力愈高**。
- 用途：變更保單內容、擴大承保範圍、加保附加險。
- 「證明保險的存在」**不是**批單的用途（那是保單、暫保單的功能）。
- 批單不能違反強制規定，例如**不能用批單承認惡意複保險有效**。

### （二）保險單的型式

| 型式 | 重點 |
|---|---|
| 時間保單 | 載明起訖日期 |
| **航程保單** | 以一段航程為保險期間，**不載明起訖日期** |
| 列舉式保單 | 只承保列明的危險事故 |
| **概括式保單（全險保單）** | 一切事故所致損失都負責，**但載明除外不保的事項不在此限** |
| **總括保單** | 用**一個總保險金額**，承保各處的貨物財產，或同一地點的多項財產 |

### （三）除外不保事項

- 一般會列出不承保的**標的、危險事故與損失**。
- 把經常性、可預期的損失除外，是為了**排除非意外事故的損失，讓費率合理**。
- 同一類危險可能在兩種保險重複承保時，通常**依性質由其中一種承保，另一種除外**。
- 載明不保事項的目的：排除不可保危險、方便保險人控制危險、避免兩種保單重複保障。

::: tip
**陷阱**：「減輕保險人的賠償責任」**不是**載明除外不保事項的目的。
:::

## 十、核保、保險費與費率

### （一）核保

核保是保險人在承保前審核、評估標的的各種危險，以決定**承保與否、承保條件、承保費率**。

- **重要性**：鑑別危險優劣、決定業務取捨、確保經營安全與利潤穩定。
- **危險選擇**：避免逆選擇、淘汰不良危險、選擇良好危險；選擇的對象包括**要保人、被保險人、保險標的物**。
- **評估因素**：要保人過去的損失紀錄、財務狀況、標的的實質危險因素。
- **次於標準的危險**仍可承保，方法是變更承保條件：限制承保範圍、提高自負額、訂定特約條款。

::: tip
**陷阱**：「放寬核保標準、多收保單才符合大數法則」是**錯誤**說法。核保的任務正是選擇危險。
:::

### （二）保險費的結構

**總保費 ＝ 純保費 ＋ 附加費用**

| 組成 | 用途 |
|---|---|
| **純保費** | 用來**支付損失（賠款）** |
| **附加費用** | 支應保險人的**各項費用成本**，例如業務員佣金、營業費用 |

- IFRS 17 實施後，「保險收入」的意涵與**滿期保費**相同。

### （三）費率的計算方法

| 方法 | 做法 | 適用 |
|---|---|---|
| **分類法** | 危險分類後，同一類別適用同一費率 | 大量、同質的業務 |
| **個別法**（判斷法） | 依個別業務狀況單獨計算，由核保人員依經驗提出、雙方商定 | 特殊、缺乏統計的標的 |
| **增減法**（經驗法） | 以分類費率為基礎，依個別危險良窳加減費 | **符合公平原則，又能鼓勵損失預防** |

### （四）產險費率自由化

- 採**循序漸進**方式，分**三個階段**實施。
- **第一階段**：**危險保費**採個別保單查核，**附加費用**採總量管制。
- 先決條件：健全的保險市場、完備的監理制度、正確的統計資料（「足夠的行銷人員」不是）。
- 任意汽車保險目前已採**自由費率**。
- 產險商品同質性高，為避免削價競爭，可從**服務、人員專業素質、公司形象**做出差異。

### （五）提前終止與短期費率

被保險人因自身原因提前終止契約時，保險人按**短期費率**計收有效期間的保費，餘額退還。短期費率比按日數比例計算的高，是因為保險人要**加速攤銷各項承保費用**，不是為了懲罰。

## 十一、再保險

### （一）意義與功能

- 再保險是**原保險人與再保險人**之間訂立的保險契約。
- 原保險契約的賠償責任仍由**原保險人**負擔；原被保險人對再保險人沒有賠償請求權。
- 功能：**分散危險責任、擴大承保能量、確保有利經營**。
- 把分入的再保業務再分一部分給其他保險人，稱為**轉再保**。

### （二）依訂約方式分

| | 臨時再保險 | 合約再保險（固定再保險） |
|---|---|---|
| 運作 | 逐筆個別洽商 | 事先訂好合約，範圍內自動分保 |
| 再保險人 | **沒有接受義務**，可決定接受多少 | 合約範圍內必須接受 |
| 優點 | 可配合個別情況、應付緊急需要；常用在**合約限額已滿**時 | 手續簡便、成本低 |
| 缺點 | **手續繁瑣、成本較高** | 彈性較小 |

兩種方式都可以用比例或非比例的方式安排。

::: tip
**陷阱**：「接洽手續簡便」**不是**臨時再保險的優點。
:::

### （三）依責任分擔方式分

| | 比例再保險 | 非比例再保險 |
|---|---|---|
| 分擔的是 | **危險**（依保險金額比例） | **損失**（依賠款金額） |
| 方式 | 依約定比例分享保費、分擔賠款 | 原保險人自負一定賠款額，超過部分由再保險人負擔 |
| 型式 | 比率再保險（成數）、溢額再保險 | **超額賠款再保險** |

- **比率再保險**：以**百分率**決定自留水準，責任分擔依**約定百分比**，不是依賠款。
- **溢額再保險**：先決定**自留額**，以「**線數**」表示再保險人責任額與自留額的關係；層次安排分散危險、線數安排平均危險，學者稱為**再保險的最佳模式**。
- **超額賠款再保險**：屬於**非比例**再保險，以損失金額分擔責任，常用來**防範巨災**；再保險人**不須支付再保佣金**。

### （四）盈餘佣金與再保險監理

- **盈餘佣金**：再保險人把合約利潤退還一部分給原保險人，鼓勵**謹慎核保**；同時降低再保佣金、改給盈餘佣金，避免原保險人把再保佣金挪去削價競爭。
- **再保險的監理範圍**：自留額度、核可的再保公司、再保險合約。

## 十二、保險監理與保險安定基金

### （一）監理方式與目的

- 經濟高度發展的國家，多採**公示方式**監理（公開財務資訊，由市場判斷）。
- **監理目的**：確保業者清償能力、增加經濟建設資金來源、發展國際保險業務。「防止業者自由競爭」**不是**監理目的。
- **設立前監理**：營業登記、繳存保證金、領取營業執照（「提存責任準備金」屬營運中的財務監理）。
- **財務監理**：責任準備金提存、資金運用、清償能力規範（「自留額限制」不屬財務監理）。
- 規定最低資本比率，作用是**確保業者清償能力**。

### （二）財務監理的數字

| 項目 | 規定 |
|---|---|
| 保證金 | 按資本或基金實收總額的 **15%** 繳存國庫（保險法 §141） |
| 資本適足 | 資本適足率達 **100%**，且最近二期淨值比率至少一期達 **3%** |
| 資本不足 | 資本適足率 50% 以上、未達 100%（或淨值比率最近二期均未達 3%） |
| 資本顯著不足 | 資本適足率 25% 以上、未達 50% |
| 資本嚴重不足 | 資本適足率低於 **25%**，或淨值**低於零** |
| 嚴重不足逾期未改善 | 期限屆滿次日起 **90 日**內，接管、勒令停業清理或命令解散 |

- 財務或業務狀況顯著惡化、不能支付債務時，主管機關可依情節為**監管、接管、勒令停業清理、命令解散**。

::: tip
**法規更新**：115 年 1 月 1 日起，保險法 §143-4 改為「不得低於一定比率」，並新增淨值比率；100% 是《保險業資本適足性管理辦法》§5「資本適足」等級的門檻。題庫第 207 題答「百分之一百」（勘誤表已改用新法源）；舊題「不得低於百分之二百」已由 115.6 v3 勘誤表刪除。
:::

### （三）保險商品審查制度

| 制度 | 適用 | 期限 |
|---|---|---|
| **核准制** | 保險期間或承保責任期間**超過 3 年**、**新型態的個人保險商品** | 收齊文件起 **40 個工作日**內核復，**75 個工作日**內准駁 |
| 核准制（駁回後再送審） | 駁回後再次送審 | **25 個工作日**內核復，**45 個工作日**內准駁 |
| **備查制** | 其他商品，保險業可逕行銷售 | 開始銷售後 **15 個工作日**內送備查 |

- 符合一定條件的保險業，可把原屬核准的新型態商品改採備查：**落實差異化管理、達到示範效果、為準則式監理作準備**。
- 我國財產保險商品審查未來朝**準則制**方向邁進。
- 「財產保險商品審查應注意事項」收錄審查會備忘錄、審查委員審理意見、相關審查原則。

### （四）保險安定基金

- 由**人身及財產保險業**提撥設立（保險法 §143-1）。
- 目的：**保障被保險人權益，維護金融安定**。
- 墊付對象：**要保人、被保險人、受益人**。
- 墊付範圍：保險賠款、保險金、退還保險費；**投資損失不墊付**。
- 設墊付範圍與限額，是為了促使消費者慎選保險公司、保障基金償付能力、避免正常經營的公司被問題公司拖累。

### （五）網路投保

題庫依 105 年版「保險業辦理電子商務應注意事項」：汽車保險、高爾夫球員責任保險、智慧型行動裝置綜合保險可網路投保；住家綜合保險**若包含傷害保險**則不在範圍內。現行規定已改採負面表列，可網路投保的範圍更大。
