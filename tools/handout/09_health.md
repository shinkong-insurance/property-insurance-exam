# 第九章　健康保險

## 一、定義與期間

- **保險法第 125 條**：健康保險人在被保險人**疾病、分娩**及其所致**失能或死亡**時，負給付保險金額的責任。
- **契約期間**：始日**午夜 12 時**起，至終日午夜 12 時止。
- 產險業經營健康保險，原則上以**保險期間 1 年以下且不保證續保**者為限；符合主管機關規定條件者，可經營 **3 年期以下**（仍不得保證續保），且**不包含一般疾病死亡**的保障。

## 二、除外責任（住院醫療保險示範條款）

**除外原因（不理賠）**

1. 被保險人的**故意**行為（包括自殺及自殺未遂）
2. 被保險人的**犯罪**行為
3. 被保險人非法施用防制毒品相關法令所稱的毒品

**除外事故與其但書**

| 除外事故（不賠） | 但書（仍可賠） |
|---|---|
| 美容手術、外科整型、外觀可見的天生畸形 | 為重建基本功能所作的必要美容或整型手術 |
| 非因當次住院治療目的所作的牙科手術 | 因當次住院治療目的所作的牙科手術 |
| 裝設義齒、義肢、義眼、眼鏡、助聽器等附屬品 | 因**意外傷害**而必須裝設者 |
| 非以直接診治病人為目的的健康檢查、療養、靜養、戒毒、戒酒、護理或養老 | 以直接診治病人為目的者 |
| 懷孕、流產（墮胎）、分娩及其併發症 | 特定情況，如子宮外孕、葡萄胎、子癇症、前置胎盤等 |
| 不孕症、人工受孕，或非以治療為目的的避孕及絕育手術 | 以治療為目的的避孕及絕育手術 |

## 三、健康保險的種類

1. 住院醫療保險（日額給付）
2. 住院醫療費用保險（**實支實付型**）
3. 癌症醫療保險
4. 重大疾病保險
5. **失能保險**：因疾病或意外致喪失工作能力，無法工作所生的收入損失
6. **長期看護保險**：保障喪失日常生活自理能力或認知功能異常

## 四、等待期間（免責期間）

| 險種 | 等待期間 |
|---|---|
| 醫療費用保險 | **30 天** |
| 癌症醫療保險 | **90 天** |
| 重大疾病保險 | **90 天** |

- 等待期間的保費排除，應在承保第一年度充分反映。
- 健康保險**續保時，不得約定**等待期間。

## 五、危險選擇

| 次序 | 執行者 | 說明 |
|---|---|---|
| 第一次（**最重要**） | 業務員 | 晤面 → 觀察 → 詢問 |
| 第二次（醫務選擇） | 體檢醫師 | |
| 第三次 | 核保人員 | 首要工作為認識危險 |
| 第四次 | 保險調查員 | |

- **BMI**＝體重（公斤）÷ 身高（公尺）²
- 健康保險危險評估，最主要從**體格**觀察。
- **財務核保**最重要的目的：評估保額是否符合被保險人的保障需要。

## 六、給付型態

- 以**損害填補為主**，**定額給付為輔**。
- 傳統醫療保險的投保限額，多以被保險人平均收入評估。

**實支實付型醫療保險：正本理賠與損害填補原則**

- **適用範圍**：113 年 10 月 1 日以後投保的實支實付型「**傷害醫療保險**」與「**住院醫療費用保險**」。
- **重點內容**：
  1. 須以醫療收據**正本**申請理賠。
  2. 同一保險事故中，所有應負給付責任的保險公司，依被保險人**實際負擔的醫療費用**共同分攤。
  3. 各公司合計給付，**不得超過實際醫療費用**。
- **意義**：落實損害填補原則，避免同一筆醫療費用重複理賠而獲利。

## 七、住院醫療費用保險（實支實付）示範條款考題

1. 手術不在「手術名稱及費用表」所列項目時，由保險公司與被保險人協議，比照表內程度相當的手術項目給付。
2. **每日病房費用保險金**包括：超等住院的病房費差額、管灌飲食以外的膳食費、特別護士以外的護理費。（指定醫師費**不包括**在內）
3. 同一次手術在同一位置接受 2 項以上手術時，按費用表中**百分比最高的一項**給付。
4. 指定醫師費屬於**不得另收費用**的項目。
5. 因同一疾病或傷害（或其引起的併發症），出院後 **14 日**內在同一醫院再次住院，視為**同一次住院**。

## 八、其他重點

1. 通貨膨脹與利率上升造成資金成本上升，醫院購買器材成本也上升，會影響長期健康保險的發展。
2. 急性病症**不是**老人罹病的最主要因素（慢性病才是）。
3. 3 年期以下健康保險，應訂有給付限額或保費調整機制。
4. **基因型疾病**：血友病、蠶豆症、地中海型貧血等。
5. **名詞**
   - **現症**：體檢時發現身體器官不正常的機能狀況。
   - 危險因素可分心理危險、實質危險、道德危險。例：醫師罹病的實質危險，比辦公室文書人員高。
   - **醫院**：依醫療法領有開業執照並**設有病房**的醫療院所，包括公立、私立、財團法人醫院。（**一般診所不屬於醫院**）
6. **膽固醇偏低的可能原因**：肝硬化、甲狀腺機能亢進、營養不良、慢性貧血、腎上腺機能不足。（腎病症候群會使膽固醇**偏高**）
7. **保證續保**的保單，保費**不得**針對個別被保險人的身體狀況調整。
8. 醫療保險詐欺最具體的犯罪型態：**偽造申請文件**。
9. 人身保險要保書示範內容自 **102 年 1 月 1 日**起，增列可詢問被保險人是否領有身心障礙證明。
10. 訂約前對被保險人施以健康檢查，或受益人申請保險金時保險公司調閱就醫資料，費用由**保險人**負擔。
