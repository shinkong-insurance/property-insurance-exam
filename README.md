# 產險考照練功房 property-insurance-exam

財產保險業務員資格測驗練習網頁（純前端、無需登入、離線可用）。

- 線上使用：https://shinkong-insurance.github.io/property-insurance-exam/
- 內容：財產保險業務員考試題庫 1,636 題，題題附答案解析，分八大類（財產保險法規與理論、火災、汽車、責任、傷害、健康、工程、運輸保險）
- 功能：分類練習、全真模擬考（產險實務 100 題/80 分 + 產險法規 50 題/50 分）、錯題本、收藏、學習進度
- 所有作答紀錄僅保存在使用者瀏覽器本機（localStorage），不上傳、不需帳號登入

## 更新網站內容

直接編輯 `index.html` 後 commit + push 到 `main` 分支即可，GitHub Pages 會自動重新部署。
